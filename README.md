# COMP2003-2023
Use this folder structure for your git repository. You may add additional folders as you see fit, but these basic folders provide the fundamental organization for evidences that need to be collected throughout the semester, so upload/commit them periodically.

This repository is for the COMP2003 Computing Group Project with the external client Genese Solutions where we are creating a Supply & Demand Forecasting System for FMCG Producer project.

We have 4 Team members for this project who have different roles to complete the finished system
Edward - data & cloud
Ethan - frontend UI & API integration
Spencer - Cyber security
Sunny - ML and forecasting

We have created a MVP (Minimum Viable Product) for the interim submission which included a Machine Learning model and a front-end system which was ran on a local machine. The plan for the second semester is to take this ML and front-end and integrate it with AWS (Amazon Web Services).
